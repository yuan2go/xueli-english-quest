# 07 · 教学质量、儿童体验与内容权利

## 1. 学习目标与不应声称的效果

本作练习词音/拼写、单字母替换和简单指令。六词集中于一小组拼读材料，适合本故事的有限设计；不是完整自然拼读课程，不据此推断覆盖全部音素规则。

完成 substitution 不等于完整 spelling；看词照抄不等于听音拼写；提示完成不等于独立完成；成人试玩不等于儿童有效性；同一局即时复现不等于长期记忆。结算不得出现“永久掌握”“英语提升百分比”等未经验证声明。

## 2. 教研逐项审核

每个词和句子检查 spelling、词义、发音标准、词音/音素区分、配图指代、语速、提示、干扰项和目标年龄语言负荷。特别检查 map/mat 词尾、cat/cap、帽子词的非互斥语义，以及 in/on 的画面空间关系。

两个 mat 同时出现时，用实体状态与场景控制避免模糊指代；本幕地图已恢复 map，野餐垫是唯一 mat。不能把含义模糊的图像当唯一正确词汇问题。公开课件和图片不因可检索而自动可用于本游戏。

审核表字段：itemId、contentVersion、text/audio/image、reviewer、reviewedAt、result、issues、resolution。没有真实审核者就保持 PENDING；开发 agent 不能凭自评填写“教研已通过”。AI 可以提出检查意见，但不能替代负责人的教研确认。

## 3. 记录口径

每个任务单独保留 assessmentMode、answerVisible、hintLevel、inputMode。重听是音频操作，不算错误或辅助泄露；显词、示范、锁定关键答案才改变证据类别。口径在 05 中定义，不能 UI 一套、日志另一套。

儿童主界面显示真实世界布置与故事后果；成人回顾显示具体观察，比如“map/mat 两次换字完成，mat 的后续拼写使用过提示”。无足够记录时写“尚无独立复测”，不强给分数。

## 4. 试玩方法

有合适条件并获得监护人同意后，少量目标用户用于观察是否知道目标、可操作、能从错误恢复和愿否继续；陪同成人不应在每次尝试前指答案。记录卡点与改动，不要求上传姓名、照片、录音。

无法开展时用成人可用性测试并标明局限。不要为了完成交付门槛让 agent 编造儿童反馈、时长或统计结论。

## 5. 体验保护

无惩罚倒计时、生命耗尽、广告、内购、竞争羞辱、无限抽奖或强迫连续登录。不能为提高完成率隐藏退出。幽默发生在角色误会，不贬低玩家。过关庆祝短而可跳过；重复错误动画缩短。

## 6. 隐私与素材

参赛版默认不采集姓名、联系方式、精确位置、麦克风或照片；记录本地存储，可清除。服务器日志只留运维必要字段，不把完整生成内容和凭据都打日志。第三方遥测默认关闭。

品牌名用于方案定位，但公司 logo、角色、真人声线、现有课件和正式发布范围仍需授权确认。不得克隆老师声音；优先原创占位素材，待授权后替换。公开仓库不应存内部资料、API Key 或儿童数据。

此为工程与产品保护措施，不构成任何地区法律合规结论；正式对外运营前由公司按实际地区、数据处理与业务形态完成必要审查。
