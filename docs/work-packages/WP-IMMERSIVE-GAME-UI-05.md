## 设计与边界

正式 `/` 进入全幅林间标题画面；开始后背景连续铺满视口。角落木牌显示当前幕，三个标记仅表达当前故事的三幕；声音与暂停位于另一角。小猫和道具是主要入口，选中后出现靠近物品、限制在安全区内的行动浮层。探险手记收纳目标、已解锁活动与制作；角色气泡表达当前回应。底部仅保留当前可用的推进/句子行动。

拼词和组句才打开纸张工具盘。工具盘展开时物品区域为它让出空间，仍可看见、点击场景；听音找物不会被模态遮罩挡住。主要提交、重听、辅助与关闭保持可达。手机竖屏不强制旋转，短横屏采用侧边工具以保留场景高度。工具内可滚动，正常探索页不滚成网页。

色彩沿用森林墨绿 `#254b3d`、深树影 `#163a2c`、木色 `#715035`、阳光金 `#e5b85b`、纸张 `#fffaf0`。标题用已有系统宋体表达绘本，界面使用系统黑体，英语字母/词块使用 Arial，避免装饰字体影响辨识。辨识点是可游玩的全幅林间场景与浮动纸张工具盘。复用当前猫和三幕资源，不生成图片、不引入外部字体或新依赖。

UI 仍只持有选中、工具、弹层与草稿；命令、身份、音频证据、教学分类、存档和同一纸张过路链由原有世界/应用层处理。动作结果先提交再展示，有界动效及 reduced-motion；不能靠动画推进目标。辅助仍明确记录，听音独立检查不泄露完整答案。
