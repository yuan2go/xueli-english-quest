# Security and content boundaries

This is a public repository. Do not commit API keys, session credentials, private company material or children's personal data. Client-side environment variables are public. No live model endpoint is included in the initialization baseline.

Treat future model output as untrusted structured data; never execute generated HTML, JavaScript, shell commands or arbitrary remote URLs. Workshop authorization, budget limits and human content approval are required before exposing live generation.

Report credential or privacy issues privately to the repository owner through an established company channel, not a public issue containing the sensitive value. Rotate exposed credentials; deleting a file alone does not remove it from Git history. Do not change repository access, rewrite history or rotate shared credentials without the appropriate authorization.

Product/asset permissions and any distribution license are to be confirmed by the owner; this file does not grant rights to company or third-party material.
