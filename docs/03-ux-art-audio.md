# 03 · 场景交互、美术和音频

当前合同：WP-ANIMATED-PLAY-LEARNING-06；游戏表面与技术边界见 11/12。本文维护视觉、输入和无障碍约束，不再保留旧页面布局规范。

## 持续游戏空间

正式入口为 Start → Game Shell。Scene 持续挂载；任务切换只换 Context Tool，不把场景变成题目插图。HUD 保留情境、暂停与探索入口；任务从场景对象/encounter 展开，不常驻练习列表。结局保留真实世界布置，记录在独立成人表面。

Desktop/横屏 Tablet：场景主区，打开工具才显示有界侧栏。Phone/竖屏 Tablet：世界占主体，工具为有界底部抽屉，内部滚动不推动场景离屏。关闭工具还原世界空间；横屏手机保留直接操控区。最低回归 360×640、390×844、768×1024、1024×768、1440×1000；不等于真机验收。

## 输入与焦点

对象、字母、词块共用 Pointer Events：单 active pointer、8 CSS px 拖动阈值、capture/cancel/lost capture、局部坐标、命中目标边界。落空/多指/旋转/后台取消不提交命令，回到原物品/草稿。落点只接受当前交互区可见且未禁用目标，不能穿透工具或弹窗。

点击/触屏/键盘等价进入相同 intent；明确提交后才判拼写和句子。重复 token 保持独立 ID。词块可拖入、排序、退回，也可按钮左右移/撤回。字母和主要控件至少 44 CSS px，文字对比和焦点可见。仅拖动表面 touch-action:none，工具允许滚动。

游戏操控区域（含背景、物品标签、字母和词块）禁用浏览器长按图片菜单、文字选择和原生 HTML 拖拽。插画不参与命中，由对象按钮接收输入；`draggable=false` 不能替代 iOS 的 `-webkit-touch-callout:none`。保护限定在 GameShell，成人记录可选取和复制。不在页面全局阻止 touchmove，不取消 pointerdown 的默认焦点行为，工具内部仍能触摸滚动。桌面 Chromium/WebKit 回归与 iPhone 原生弹窗验收分别记录。

工具打开定位焦点，Escape 收起并回到触发对象；提交后聚焦实际结果物品或场景。弹窗约束焦点，关闭恢复；aria-live 只播短反馈，不朗读每帧坐标。完整答案只在教学/明确帮助模式公开，沿用现有证据口径。

## 表现层

选择/按下/合法目标即时反馈；受阻保留物品与草稿并说明修复动作；正确收纳句被关闭的背包挡住时，工具内可先真实开包，保留整句后再提交；成功/制作/变形/移动/角色反应来自已提交结果。变形保留同一实体 ID；铺路明确显示同一纸张和伙伴过路。关键抵达/结局短演出可跳过，不阻止业务保存；reduced-motion 直接稳定终态。暂停、后台、刷新和旋转清理瞬时表现，绝不由动画推进 world/goal。

## 唯一资产链

`content/manifest.ts → visual-assets.ts → public/assets/game/tabby/`，遵循 Vite BASE_URL。主角不镜像：灰项圈、绿围巾、画面颈部右侧白色定位器保留。纸偶与伙伴不同实例。帽子/垫上/包内物品按父对象局部位置显示；主角/帽子可独立命中。

暖纸、墨绿、赭黄取自 `ui/tokens.css`；清晰系统字体，小写字母 Arial。来源、masters 和历史参考见 design/tabby；旧整页参考仅 historical，不再约束当前构图。512px 欢呼图不冒充高清 master。

资源分 critical/scene/lazy 生命周期，加载失败提供可操作文字轮廓与重试；重试不清除输入/世界。StoryAudio 是唯一可取消通道，首个手势激活，新任务取消旧声音，后台停止，恢复可重听。语音资源仍 PENDING/path=null，浏览器 TTS 必须标开发语音；不能把字母名当音素或用播放成功证明听懂。正式录音、教研与素材权利独立验收。
