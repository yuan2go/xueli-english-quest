# 03 · 场景交互、美术与音频

Refoundation 06 目标规范；当前实现见 STATUS。产品体验详见 [11](11-web-game-product-blueprint.md)，表现与生命周期实现见 [12](12-web-game-technical-design.md)。

## 界面结构

正式首页优先“开始/继续冒险”，次级为魔法工坊、词语册、设置。新主章节接入原 `/`，不另建展示用入口。保留旧故事时作为明确的既有章节，不让它继续占据新玩法唯一主入口。

场景持续可见，占主要游戏空间；HUD 只呈现当前目标、暂停/重听、撤销和必要工具。不要常驻课程目录、目标勾选清单、分数面板或叠放卡片。对象选择后出现相应操作，关闭工具回到原场景与焦点。

手机纵屏：场景与有界底部工具区，词块区独立滚动，不让目标对象离屏。手机横屏/Pad 可使用侧工具区；不强制横屏。基准为 360×640、390×844、768×1024、1024×768、1440×1000，并验证旋转、软键盘与安全区域。以上是模拟视口，不是实体设备。

## 操作

沿用统一 Pointer Events adapter：单 active pointer、capture/release、cancel/lostcapture、拖动阈值、局部命中、遮挡与禁用检查。阈值可按实际触屏测试调整，不写死设备像素。点击选择再点目标、拖放、键盘执行同一命令；核心操作不依赖 HTML5 桌面拖放。

拖动轨迹仅为操作草稿。落点提出搬运意图，规则验证通过才改变世界；不能绕过障碍、门、隐藏容器和角色可达性。落空/多指/旋转/后台取消不构成语言错误。关键命中区至少 44 CSS px，字母/词块间距避免误触，不能以扩大透明区遮挡邻居。

重复词块保留独立 ID，支持拖入、插入、重排、退回及按钮等价操作。输入完成后显式提交才判语言；不随拖动试错连续计错。需要指代消歧时让玩家选对象，不暗中替玩家换成能完成任务的对象。

弹窗限制焦点；Escape/关闭恢复触发处；对象消失后焦点回到结果或场景。aria-live 只播简短结果。工具开放不自动泄露独立任务答案；仅颜色、形状或固定槽位即可作答的任务不能声称独立词义识别。

## 因果动画

用同一实体的稳定 ID 贯通源位置、路径、目标与子物品。移动沿规则给出的路径，物品进入包口后隐藏，箱子放大影响碰撞/支撑范围，门开启改变通路，小猫受阻停在合理位置。禁止用另一只猫或移动副本长驻制造跳变。

表现消费已提交的结果，不在 animationend 推进业务。几何分批读取，优先 transform/opacity 补间；角色待机、观察、走路、受阻、操作、庆祝是有限状态，不用全局持续帧循环。状态再次变化时取消旧 cue，从当前可见位置过渡到最新权威终态，不让旧动画覆盖新结果。

输入反馈和短动作应及时；演出默认短且可跳过，不以秒数自称体验达标。暂停、后台、旋转、刷新、跳过及 reduced-motion 都回到一致稳定状态。持久化保存的是逻辑结果，不是动画进度。仅动画播放顺滑不能证明核心好玩。

## 美术交付

保留棕灰底色、深色虎斑、金黄眼睛、浅色口鼻的狸花猫；灰项圈与画面颈部偏右白色圆形定位器不被绿围巾遮挡，不镜像换边；背包保持一致。纸偶与主角不能混用图像身份。

沿用暖纸、墨绿、赭黄、书页、字母印块和湿墨小径；学习对象和操作结果是视觉重点。场景背景、可操作物品、角色姿态分别生产与登记；正式英文/中文由 DOM 或文字层绘制，不能烘焙进背景。新道具可用风格一致的原创矢量制作，不能拿网络截图拼贴。

单一 manifest 记录 assetId、用途、source/master、派生步骤、尺寸、真实 alpha、字节、hash、许可与审核状态。整页参考图不是运行时资产；合集切片/低清放大不能标为独立高清 master。现有 512px 姿态图不冒充高分辨率源稿。资源入库与实际页面引用分别核验。

## 音频与降级

沿用唯一可取消 StoryAudio 通道。首个明确手势激活；换任务、关闭、后台停止旧声音；恢复后允许重听。语音、短反馈和音乐有明确优先级，不重叠讲解。不能把字母名称当自然拼读音素。

正式录音须逐词/句登记、听审。未审核 TTS 明示开发语音；缺音频时允许文字辅助继续，但改记文本辅助/听力未评估，不能无声通过独立听力任务。资源 critical/scene/lazy 加载、重试仅失败资源，不清草稿或世界。
