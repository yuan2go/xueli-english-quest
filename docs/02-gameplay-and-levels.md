# 02 · 游戏机制与逐关规格

## 1. 世界和胜利条件

糊涂风吹乱绘本文字。玩家帮助小猫准备物品、穿过树林、布置野餐，修复三页绘本。完成第三页全部任务才进入结局；不以分数、速度或重试次数决定输赢。

词表 cat / bag / map / mat / hat / cap；位置关系 in / on。旁白和功能性英语不受六词限制，但需简短、审核、不能当额外学习成绩。普通模式逐步撤掉答案提示；引导模式可给中文解释和文字示范。

### 权威物品实例

- cat-companion：陪伴角色，词 cat，禁止变形，允许按目标移动。
- bag-main：背包，词 bag，可容纳物品；内部物品保留记录与可见入口。
- route-sheet：第一张地图，词 map，变成 mat 后仍是同一实例。
- hat-main：宽檐帽，词 hat。
- cat-card：施法卡纸偶，词 cat，可变 cap，绝不替代 cat-companion。
- picnic-mat：第八关新生成的 mat，与 route-sheet 不同。
- ink-road：场景区域，不是英语词汇物品。

实例与词汇分离：两个物品可以共享一个词；一个实例可以变词；物品不可在地图和垫子形态下同时存在。

## 2. 三种玩法

### A 拼词造物

题目播放目标音。下方出现槽位与有限字母，点击或拖动填入，点击“施法”才提交。未填满不判错；调整字母不计错。教学可以显示答案，听音检查默认隐藏完整词。

正确词生成一个任务物品；可识别但非本次目标的词只显示短暂投影，不写入权威世界，以免引入多余道具或任务死局。反馈为“这是另一个物品，我们现在需要……”，不说它不是英文单词。未收录组合也不声称英语不存在该词。

### B 换字变物

只允许 map↔mat 与 cat-card 的 cat→cap。替换一个字母后点击施法，原实例原子变化；突出变化位置→播放目标词→物品变化。hat→cap 不属于一次单字母替换，禁止作为这一机制的示例。

变形要检查来源形态、实例、当前步骤和任务阶段。被其他物品使用的容器/支撑物不能随意变形；主角不能变形。地图铺路后不能在小猫仍在路上时撤走。对源物品的点选不构成语言错误。

### C 听音互动

select 为听词点物；place 为听句摆物。提供拖放和“先点物品、再点目标”两条等价路径。正式检查不闪烁唯一正确目标、不把答案留在按钮文字里；屏幕阅读辅助可提供必要文本，但标记为文字辅助，不计纯听力证据。

in / on 的空间目标要明确。不做精确物理题。物品错、目标错、关系错一次仅解释首个问题；落空属于操作错误，不计语言错误。

## 3. 十二挑战／十三步骤

表中音频及文案为待教研审核的创作草稿。每个 step 必须有明确入口、完成效果和退路；编号固定，便于内容、日志、测试及视频对照。

| 挑战/step | 场景与目标 | 输入与允许帮助 | 权威完成效果/学习口径 |
| --- | --- | --- | --- |
| 01 / s01 | 家门口；唤醒小猫 | 引导拼 cat，可显词并演示；音频 cat | 创建 cat-companion；teaching，不算独立拼写 |
| 02 / s02 | 准备背包 | 听 bag，字母 b/a/g + 适量干扰；主动提示可用 | 创建 bag-main；记录 spelling，是否撤掉答案必须在日志体现 |
| 03 / s03 | 找回地图 | 听 map；m/a/p/t；可能误成 mat | 创建 route-sheet(map)；错误 mat 仅投影，不永久生成垫子 |
| 04 / s04a | 湿墨阻路；先变垫子 | route-sheet 的 map→mat，只替换末位 | 同 ID 变成 mat；不立即算第四关完成，不提前放行 |
| 04 / s04b | 把垫子铺在湿墨上 | 拖动或点击 route-sheet→ink-road | 设置过路逻辑状态 crossed-ink；表现小猫走过；此步为操作，不当英语答题 |
| 05 / s05 | 通过后恢复地图 | 必须 crossed-ink；mat→map | 同 ID 恢复 map 并收回操作区；地图指向下一站 |
| 06 / s06 | 找回宽檐帽 | 明确点名 hat，拼 h/a/t | 创建 hat-main；不做“所有帽子只能叫 hat”的图像排他题 |
| 07 / s07 | 纸偶变换装帽 | 进入时创建一次 cat-card；cat→cap | cat-card 同 ID 变 cap；主角仍存在；记录 substitution |
| 08 / s08 | 野餐地；新铺垫子 | 听 mat，从零拼写，延迟回访 | 新建 picnic-mat；可做摆放到野餐地的非测验演出；不是把地图复制成垫子 |
| 09 / s09 | 收好换装帽 | “Put the cap in the bag.”，物品和目标可选择 | cat-card in bag-main；首次可引导 in，标注 guided |
| 10 / s10 | 整理宽檐帽 | “Put the hat on the mat.”；本幕 mat 唯一指 picnic-mat | hat-main on picnic-mat；首次可引导 on |
| 11 / s11 | 确认路线 | “Find the map.”；地图、垫子、背包均可见 | 选 route-sheet；不删除物品；lexical-listening，不算拼写 |
| 12 / s12 | 小猫入座 | “Put the cat on the mat.”；撤掉答案高亮 | cat-companion on picnic-mat；全主线结束；新的组合，非已掌握证明 |

12 个挑战不等于 12 次点击；s04a/s04b 是一个挑战内的两个操作。动画、音频重听、教学演示、确认按钮也不算额外关卡。

## 4. 每关的具体节奏

enter：加载本关必要资源，保证已有物品和已批准的 onEnter spawn 正确；最多一条当前任务。首次用户点击后初始化音频。

present：短故事事件＋目标音；教程可显示完整词。若音频失败，提供重试或显式文字辅助模式，不能悄悄变成看答案的听力题。

interact：字母输入或物品选择。操作反馈即时，提交反馈可稍后；施法/放置只发一个带 stepId、attemptId、expectedRevision 的命令。

feedback：正确先提交领域状态，再播放动画；动画期间防重复输入，结束或看门狗超时均可回到同一正确状态。错误不推进世界；反馈后可继续。

advance：写入完成证据、更新步骤与存档；第四关仅在 s04b 后修复相应进度。结局页从实际完成记录生成，不写虚构学习成果。

## 5. 错误、帮助和复习

WP-STORY-EXPERIENCE-02 已实现每步受限因果反馈：唤醒、背包出发准备、展开地图、同纸变形、铺路通过、恢复导航、短暂试戴、纸偶变帽、新垫子铺开、收纳/摆稳、地图到达和野餐。反馈先提交再表现；换字依次强调词尾、目标词音（缺失明确降级）、物品变化和用途。演出可跳过，不可跳任务。试戴和小猫误会是临时表演，不改变权威位置。

摆放目标直接在场景中：背包内部 in、垫子表面 on、尚未跨过的湿墨 across。目标由世界语义定义，点击和拖放共用提交链；源、地点、关系依次解释第一个错误。不会提供“垫子里面”或自动改正到正确地点。s03 的 mat 错词呈现临时垫子和小猫想休息的反应，保留字母，重复时缩短，不要求先答错。

首次拼词教程随放入/取回/替换操作更新，摆物教程到实际需要时出现。帮助从关注位置/物品到明确对比，再到可观察的字母/摆放示范；示范不调用提交，玩家必须亲手复现。帮助暴露留在日志中，刷新不会恢复“独立”口径。修复项从成功事件派生，s03/s07/s12 分别完成三页；结局以真实野餐、三页和可重听词卡为主，成人摘要是次级入口。

重听不扣分、不自动算提示；未填满或落空不记录错误答案。第一次语言错误重播目标并允许重试；下一次提示相关位置/物品；仍困难则给对比；最后演示并要求复现。实际帮助按 hintLevel 记录，不能因为后来答对就清零。

已知错词可有约 0.8–1.2 秒轻幽默，如 mat 投影让小猫误以为可以休息；连续同错缩短或跳过重复动画。玩家不是笑柄；无扣生命、羞辱、红屏、排行榜或付费复活。

map/mat 在 03、04、05、08、11 复现，但题型不同，不能合并成五次独立拼写。最多插入两个短复习，不无限延长主线。首版先实现固定复现，动态插题排在后续工作包。

## 6. 解决场景与教学之间的冲突

地图→垫子用于观察单字母变化，故事画面已暗示所需物品，因此不当纯听力测验。铺路 s04b 是因果玩法，不强记英语得分。in/on 初次展示属于教学；只有换物品组合并撤掉答案提示后的操作才记为新的理解观察。

hat 可作为更宽泛的帽子概念；cap 是本次明确目标词。避免“看一张帽子图只有一个合法单词”的判法。这里的场景资源区分不等于严格的词义互斥关系。

## 7. 结局和重玩

儿童页展示修复的三页、野餐画面与词卡，不贴能力等级。成人详情页按词/题型显示尝试、提示与复现情况。通关回顾使用已审核语句，不让 AI 临时夸大学习成效。

自由野餐为 P2：只使用已实现物品和放置点，不按主线订单判错、不计入主线学习证据。重玩可变字母顺序、干扰项与合法物品布局，不变语音含义或任务可达性。学习主线与自由模式独立存档。
