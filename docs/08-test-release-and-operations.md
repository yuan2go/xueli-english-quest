# 08 · 必要测试、发布与运行手册

## 1. 测试原则与当前命令

优先测试真实风险，不为指标堆叠快照、重复用例或空断言。领域测试不能替代浏览器，更不能替代真机、教研或真实 Provider。所有结果记录环境、命令、退出状态和未覆盖项。

```sh
npm test
npm run typecheck
npm run build
npm run preview -- --host 0.0.0.0
npx playwright install chromium
npm run test:browser  # build 后运行；自动启动生产 HTTP 预览
```

npm test 使用 Node 原生测试器与 TypeScript 类型擦除。它运行逻辑，不代替静态类型检查。锁文件已生成，CI 使用 npm ci、类型检查、构建和 Playwright。Playwright 启动实际生产 HTTP 服务；模拟触控、视口和故障注入均不是实体设备验收。最新结果见 STATUS 与 evidence/playable-story。

## 2. 分层必要覆盖

| 层次 | 核心用例 | 不能证明什么 |
| --- | --- | --- |
| 领域单元 | map↔mat 身份保持；主角保护；无效变形；重复生成；旧 revision；目标合法性；被占用目标禁止变形 | 游戏 UI 能玩 |
| 会话集成 | s04a→s04b→s05；禁止绕过；重复 attempt；错误不推进；帮助口径；原子保存与恢复 | 真机触控/音频正常 |
| 内容验证 | 全十三步可达；资源存在；未知词/非法步骤拒绝；cat-card 与主角独立 | 英语教学质量正确 |
| 浏览器冒烟 | 点击完整通关；移动视口拖放与取消；重开/继续；音频失败；无 API 时主线仍能玩 | 真实 iPhone Safari 等价 |
| AI 工坊 | 未授权拒绝；限流/超时/预算；非法 JSON/状态；一次真实生成与可玩预览 | 长期稳定或学习效果 |
| 人工检查 | 真机、音频逐条、教研、素材授权、实际 URL 可达 | 没做的数据可被推定通过 |

浏览器推荐 Playwright，在 WP-01 加入最小冒烟；不要求全页面截图矩阵。模拟触屏和 WebKit 能发现问题，但不能替代 iOS 真机。开发环境无法运行某层时明确 NOT_RUN/BLOCKED，不伪造 PASS。

## 3. 必须覆盖的异常

字母未填满、重复字母 token、拖到错误槽、落空、多指和 pointercancel；连击施法；过期动画回调；翻页途中刷新；s04a 后恢复；小猫过路中刷新；损坏/旧版本存档；存储不可用；音频未解锁、404、叠播、后台恢复；屏幕旋转；语义模糊目标；未审核素材；生成缺失实体或无限循环关卡。

必要回归以失败模式为单位，一条清楚的参数化测试可覆盖相同不变量。改判题要跑领域＋会话＋关键浏览器；改资源要跑资源索引＋加载＋教研；只改文字文档不自动跑全部浏览器。

## 4. 真机验收表

至少 iPhone Safari、Android Chrome、iPad Safari 完整流程各一次，记录具体系统/浏览器版本、网络、方向与操作者。评审在微信访问则补微信内置浏览器。初始状态全部为 NOT_RUN，不能提前勾选。

逐项：首次点击能开始且音频可听；不看桌面说明能理解目标；触控不误判；字母清晰；页面不溢出；暂停/重听/继续/重开可用；错误可恢复；完整结局；主线无实时 API 依赖；最终 URL 从手机外部网络打开。

## 5. 发布门槛

Release 允许：R01–R09 全部完成；必要自动检查通过；教研审核真实完成；三类目标真机证据；无密钥或未授权素材；稳定 HTTPS 地址；说明反映真实交付。

Release 阻断：主线任意死局、静默丢档、关键语音缺失、答案泄露但声称纯听力、生成内容可执行代码、儿童数据外传、公开 API 无鉴权/限流、未确认版权素材被发布。AI 工坊未完成可明确关闭并写入设计说明，不单独阻断已完整的主线。

初始化的领域测试 PASS 不能被解释为此 Release Gate PASS。

## 6. 部署和回滚

构建静态 dist，保存构建 SHA、内容版本与资源 manifest；明确 base 子目录。不要把 npm run dev/preview 当生产服务。先 staging 验证，再把稳定地址提交评审；源代码仓库和体验 URL 分开。

提交前手机扫码/直接访问，检查证书、首屏、音频、子路径、缓存。建议提供 60–90 秒录屏作备份，但视频不替代可体验 Demo。提交后建议至少维持到 2026-09-28，公布时间若调整则跟随实际要求。

回滚到上一完整代码＋内容＋资源版本，不能只回退 JS 而保留不兼容内容。清理错误缓存不删除用户未确认的学习记录；版本变化需有恢复策略。工坊故障先关闭在线入口，不影响静态主线。

## 7. 比赛提交清单

体验 URL、可扫码入口、简短设计说明、实际 AI 使用记录；建议附演示视频与版本号。说明玩法、主题、用了哪些 AI、核心亮点、已实现范围和限制。不得声称尚未完成的实时生成、适配产品或教学成效。

视频建议先展示 map/mat 因果，再展示听句摆物和结局，最后展示真实或明确离线的工坊；剪辑过程标明，不把录好的结果冒充现场生成。
