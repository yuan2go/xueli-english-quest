雪梨英语奇旅是一款纸上英语工具解谜游戏。玩家与同一只狸花猫观察问题，使用词语改变大小、创造物品、发出指令或观察描述。正式 React 页面保留世界，工具按需打开，手机使用有界底部抽屉。

R1 围栏取篮既能搬箱子变大托高小猫，也能让小猫缩小穿洞后开内侧把手；两种解法由同一净空/支撑/可达规则产生。R2 用大小、容纳和窄通道组合装运，R3 的英语请求决定 in/on 关系；结局读取真实交付和猫的位置。封洞回访让之前的办法需要调整。

WordSpell、词义小样、辅助/独立句子与拼写、词语册共用内容与规则。描述不能施法；语言正确、任务满足、世界允许分别记录。撤销和重开不会洗掉帮助，工坊物品不能带出绕过关卡配额。旧成绩不变成新成绩。

一个 React/TypeScript/Vite 应用、一个 domain.transition 写入入口、有限节点图与显式版本；没有物理引擎、后台、账号或实时模型。稳定实体和关系子树驱动动画，动画不驱动状态。确认的狸花猫沿用原资产，四个新物品以原创 SVG 分别登记、核验并实际引用。

工程测试与模拟视口自检已完成；真实设备、儿童趣味性、教研、正式语音和独立视觉/权利审核仍待完成。开发语音明确标为未审核 TTS，没有学习提升或永久掌握声明。AI 实际使用见 [制作记录](ai-usage-log.md)，没有调用运行时 Provider。
