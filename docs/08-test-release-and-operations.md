# 08 · 必要验证、发布与运行

Refoundation 06 验收合同。目标、已执行与阻塞分开；本文件列出要求，不代表检查已运行。实际结果写 STATUS 和对应实现 SHA 的证据。

## 当前可用命令

基线使用 Node >=22.12.0 与真实 npm lockfile：`npm ci`、`npm test`、`npm run typecheck`、`npm run typecheck:domain`、`npm run build`、`npm run check:resources`、`npm run check:release`、`npm run test:browser`。测试是 Node test runner，不假设存在 Vitest、lint 或新 check:levels 命令。`npm run check:levels` 已实现，使用同内核受控枚举，`-- --write` 输出见证与预算。

浏览器套件需要已安装 Playwright 浏览器；当前生产构建预览回归使用 4174 端口。禁止只测开发组件、注入完成状态后截图或编造真实儿童数据。不为文档变更无差别跑全部游戏套件；修改玩法/语言/存档必须运行相关真实回归和最终构建。

## 验收矩阵

| ID | 必须证明的行为 | 有效证据 |
| --- | --- | --- |
| G01 | R1 两种机制不同的解法可达成同一目标 | 同一规则执行的见证轨迹，加从正常首页的 HTTP UI 运行 |
| G02 | 尺寸真实影响通行/支撑/容纳，不只贴图变化 | 正/反例领域检查；跨对象和另一关重复使用 |
| G03 | 拖动不能穿墙、远程开门或取出封闭内容物 | 规则拒绝、无半提交，UI 短反馈后可继续 |
| G04 | 主角/物品身份、关系子树、配额与旧过路规则保持 | Domain/Application 回归，容器带子物品移动与占用拒绝 |
| G05 | 指令/描述/任务/世界许可分开 | 短句、多模板、重复 the、歧义、outside、blocked、不改世界的描述 |
| G06 | 单次提交、过期命令、重复 attempt 与取消正确 | 幂等/revision/模式验证；pointer cancel/lostcapture/多指/旋转 |
| G07 | 撤销恢复整次世界动作但不洗掉帮助/尝试 | journal 重放、目标重算、再次操作及刷新 |
| G08 | 新旧存档、内容版本与回访确定性正确 | 已知旧 fixture、损坏/未来/超限/存储失败、备份读回、隔离恢复 |
| G09 | 工坊/主线/回访/词语册实际接通 | 正式入口完整章节与往返，非独立 Demo，不把工具物品带出 |
| G10 | 动画和音频不影响事实、响应式可操作 | 正常/跳过/后台/reduced-motion/刷新状态一致，音频取消与失败降级 |
| G11 | 资源有真实来源、引用和审核状态 | 唯一 manifest 的格式/尺寸/alpha/hash/字节/路径检查、页面引用 |
| G12 | 新章节确实引出选择、后果和迁移使用 | 关卡设计与成人工程观察；儿童趣味性另有真实观察 |

单测检查公开行为与不变量，不按每个私有函数堆数量；参数化覆盖必要边界即可。保留历史 decoder/规则测试；已退役 UI 用例可在记录替代覆盖后更新，不通过删断言、吞错误或 skip 所有失败换 PASS。

## 可解性检查

对有限状态/动作的已编排关卡，用同一 transition 与目标函数运行有界搜索或受控枚举；输出内容/rulesVersion、节点预算、结束原因及可重放 witness。排除 journal/动画等与谜题无关的维度后计算状态键，但不能遗漏影响规则的属性、位置、配额、门状态与携带关系。

R1 至少两条不同关键条件的见证，换序不算不同策略。超时/预算耗尽只能是 UNKNOWN，不是不可解或通过。搜索不调用 UI 私有捷径；独立的手工成功脚本不替代规则验证。所有参考轨迹还须在正式 UI 上能操作，求解器通过不证明孩子会操作或游戏有趣。

## 设备、性能与观察

模拟视口包括 360×640、390×844、768×1024、1024×768、1440×1000 和旋转；触屏/鼠标/键盘语义一致。实体 iPhone Safari、Android Chrome、iPad Safari 分别记录系统/浏览器版本、网络、方向、步骤、异常。模拟 Chromium/CDP 或桌面 WebKit 不冒充实体 Safari。

选择一组一致设备/浏览器/CPU 限制与场景，记录拖动、属性变化、开门和子物品移动前后耗时、long task、layout、控制台和内存/监听清理。输入反馈及时、动画不中断因果是目标；没有测量不写 60fps、性能提升百分比或“真机流畅”。优化不能通过隐藏关键对象、缩小命中或跳过动画因果换指标。

儿童试玩按 07 匿名记录目标理解、自发策略、纠错、帮助与重玩意愿。缺少儿童样本不阻断其余工程，但 FUN_VALIDATED 保持 NO/NOT_RUN；不把成人通关当替代。

## 发布与回滚

工程演示、受控审核预览和正式公开发布分开。公开发布要求当前代码与必要测试、资源权利、内容/发音审核、目标设备证据及真实 HTTPS 部署验收。`check:release` 对未审核项继续失败；没有正式审核不删除门槛或写空审核人。预览不足以声称生产/教学完成。

文档提交到 main 不等于部署。部署需核对已有托管渠道与授权；不要仅根据仓库无 homepage 推定没有站点，也不要新建第二个站点。若无可用权限则部署 BLOCKED，保留可构建产物和明确操作说明；不伪造体验 URL。

记录 code SHA、content/rulesVersion、manifest、实际 URL、base 子路径、构建缓存/资源完整性、首次音频、刷新和回滚版本。Vite preview 只用于本地验证，静态 dist 才是部署产物。回滚保持代码/内容/资源一致，保留未知新档，不删除旧数据。CI 开关与权限按本轮真实读取报告，不擅自启用/降低安全控制。
