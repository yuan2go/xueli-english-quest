# 06 · AI 制作与安全边界

本轮不实现运行时 AI、在线 Provider、开放聊天、麦克风评分或在线 AI 关卡平台。儿童“魔法工坊”是本地学习/练习表面，不是 AI 服务。缺少模型凭据不阻断确定性游戏开发。

AI 可以在开发期帮助提出关卡候选、词句草案、规则反例、原创美术/音效和代码。候选进入正式内容前，需要人工内容/教研与权利审核，并通过同一游戏规则的可解性/行为验证。不要为了证明 AI 深度另造一个后台或自动路由平台。

实际制作记录沿用 docs/submission/ai-usage-log.md：工具/模型、实际使用日期、输入目的、产物路径/版本、人工修改、验证与权利状态。只记录发生过的行为；草稿、fixture、真实调用、内容审核分别报告。模型生成一份方案不等于系统具有自动关卡生产能力。

所有玩法判题本地确定性执行。模型内容不能成为任意 HTML/JS、eval、远程 URL、插件或工具执行来源。不把 API Key 放进客户端、VITE_*、仓库、日志、示例文件或截图。凭据与预算需要另行明确授权，前端变量没有秘密性保障。

不收集儿童姓名、联系方式、精确位置、照片或麦克风；第三方遥测默认关闭。成人/儿童试玩记录本地匿名化，不向公开仓库上传身份或录音。公司内部课件、logo、教师声线和材料未经允许不入库。参赛背景可简述，不复制内部公告、奖池和人员信息作为公开文档素材。
