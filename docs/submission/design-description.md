## 作品与主题

雪梨英语奇旅 / Xueli English Quest。儿童与狸花猫进入“纸上小径”，把词语作为工具，创造物品、改变大小、发出指令、理解线索，用自己的办法帮助伙伴。沿用一个触控优先 Web 应用，不增加独立平台或平行 Demo。

## 目标玩法

观察问题 → 选择对象与英语工具 → 世界产生可见后果 → 调整办法。目标章节包含三关及一次改变条件的回访；学习工坊提供词义、拼写与基础句型的引导/辅助/独立练习，词语册保存实际使用记录。

核心示例为围栏取篮：可用箱子变大作为台阶开门，也可让同一小猫缩小穿洞后从内侧开门。尺寸、可达性、支撑和开合必须是真实规则；两种方案、完整章节和手机体验仍待实现验证，不能按本草案宣称已经可玩。

## 核心亮点与学习边界

英语选择影响实际世界，不是答对以后附赠一段动画；指令执行、描述观察，语言正确与任务完成分开。允许撤销和再尝试，帮助与独立完成分别记录，不声称永久掌握或未经验证的学习提升。
