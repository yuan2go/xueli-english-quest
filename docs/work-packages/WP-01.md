# WP-01 · 核心机制可玩切片

状态：READY。前置：读取当前 main 与 docs/STATUS.md；本包不是重写蓝图，也不是只补文档。一个 agent 负责实现，另一个独立审查。

## 目标

把初始化的开发验证页升级为一段手机可玩的游戏：听到 map → 用字母拼出 map → 地图出现 → 将 map 换成 mat → 把垫子铺到湿墨路上 → 小猫通过 → 再把 mat 换回 map。整个流程不依赖在线模型，不需要登录。

## 必做范围

1. 在可联网环境解析当前 package.json，生成并提交真实 package-lock.json，统一 npm ci。核对 Node/类型/构建兼容，不盲目升级全部依赖。安装失败如实报告，但继续可执行的领域工作。
2. 将开发按钮换为真实字母盘、槽位、施法、选择物品与放置交互。保留点击路径并增加 Pointer Events 拖放与取消。手机最小 360 宽可用，不依赖鼠标 hover。
3. 保留领域内核，补 GameSession/Step runner：s03、s04a、s04b、s05；当前 step 守卫、expectedRevision、attemptId 去重、输入反馈、可恢复阶段。切片使用独立 packId 和明确 initialWorld，不假装之前 01/02 已被玩家完成。
4. map↔mat 同 ID；s04a 后不能跳到 s05，必须铺路；禁止重复生成、动画回调重复奖励或小猫通过中撤走垫子。cat-companion 不可变形。
5. 正确词/已知非目标词/未收录组合分别反馈；错误投影不进 world；未填满/落空不计语言错。提供重听和逐级提示，学习口径分开。
6. 接入 AudioService 的本地音频资源合同和首点解锁、取消叠播、失败/文字辅助路径。没有经审核音频时允许显式开发替代，但必须写 BLOCKED_REVIEW，不能把它作为正式听力验收通过。
7. 基本场景与变形/过路表现，资源用原创或明确可用占位。加入 reduced-motion 与逻辑超时退路，不以 animationend 唯一推进。
8. 保存每个已提交步骤，刷新能从 s04a 或 s04b 正确恢复；提供继续/确认重开/清除本地记录。损坏或不兼容存档有明确恢复提示。
9. 做必要领域、会话、浏览器冒烟并修复实际失败。更新 STATUS 和交付报告，只汇报实际运行证据。

## 允许自主决策

组件划分、局部样式、轻量动画实现、存档封装、测试组织可自行判断；避免通用状态机平台或整套新引擎。真实小游戏手感比架构层数重要。可以为本包加入最小 Playwright 冒烟，但不做无必要截图矩阵。

## 不在本包

完整十二关、正式素材全集、在线 AI 工坊、家长账号、积分、排行榜、复杂自由模式、语音识别、多模型 Router。不要因为无 API Key 停止这个工作包。

## 必要验收场景

- 正确完成四个底层步骤；两个形态不同时存在。
- mat 错词投影后改回 map，世界无额外实例。
- 连击施法、旧 step/旧 revision、重复 attempt 均无重复效果。
- 地图变 mat 后直接尝试恢复 map 被步骤守卫拒绝；合法铺路后才允许恢复。
- 点击与触屏拖放可完成同一流程；落空/pointercancel 不计语言错误。
- s04a 后刷新仍需铺路，s04b 后刷新不丢 crossed-ink。
- 音频失败可以重试或明确辅助，不静默泄露答案仍计独立完成。
- 无 Provider 网络请求，离开页面无残留音频/计时器。

## 交付

npm test、npm run typecheck、npm run build；新增最小浏览器流程的实际结果；真机若未运行明确列出。交付 baseline/final SHA、页面启动方式、实现范围、真实视频/截图（若确实产生）、剩余阻断和 WP-02 接口建议。提交或 push 按当前用户授权，不自动 force-push 或覆盖其他 agent 的修改。
