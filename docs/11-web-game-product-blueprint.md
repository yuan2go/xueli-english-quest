# 11 · 项目蓝图：可玩的英语纸上冒险

Refoundation 06 / 产品设计与实施边界。本文将产品方案组织为玩家体验，具体范围由 01、关卡规则由 02、教学口径由 07 定义，不重复建立第二套合同。当前代码不因本文提交而自动具有这些能力。

## 1. 一句话定义

孩子和狸花猫走进纸上世界，把词语当成可使用的工具，创造物品、改变大小、发出指令并理解线索，用自己的办法帮助伙伴。

这不是一款需要先答题才能继续看的绘本，也不是把收集、经营、拼词战斗、跑酷一起摆进首页的小游戏合集。首版的乐趣只有一个中心：对一个看得见的问题提出办法，并看见世界按一致规则作出回应。

## 2. 项目是否重开

不新建仓库、独立应用或平行 Demo。保留产品识别、可用资产与工程能力，在同一产品中重做主玩法。原《小猫的野餐冒险》可以是保留内容，不要求它继续占据主玩法位置；不因沉没成本保留机械步骤，也不因旧版枯燥就否定所有基础设施。

重做范围是问题设计、可组合规则、主界面、关卡和主循环；可以实质改写领域模型。复用范围是经检查仍适合的触控、词块操作、音频、资源加载、确定性状态和保存边界。不是“换皮/加动画”，也不是“换个项目名从头搭平台”。

## 3. 首次进入的体验

首页一句自然的邀请和开始/继续按钮，孩子进入场景后立即看见伙伴与问题，不先选择年级、课程树或填写账户。小猫以短动作展示够不到、过不去等困境，目标文字与语音简短，不列完整解决步骤。

第一次新工具出现时，旁边用可操作小样表达含义：同一物品大/小、门开/关、物品在里面/上面。孩子试过后，工具保留供当前问题使用。示范是支持，不把跟随结果说成独立能力。

之后主要操作留在场景：选择对象、挑一个词、执行、看后果。必要时打开拼词/组句工具；提交后回到原场景，成功不自动拉出下一道题。遇到受阻，保留草稿并允许改一个决定，而不是从头完成整串输入。

“首分钟能看懂目标并发生一次自主改变”是设计目标，不是已经测得的留存指标；具体节奏要用实际观察调整。

## 4. 三层乐趣

即时层：物品跟随手势，有合理落点和回退；大小、门、容器及角色的变化看得懂；反馈短，不只是贴图漂浮和无意义发光。

单关层：至少在核心关，孩子需要决定用哪个对象、改变什么、先做什么。错误选择的后果提供信息，有撤销和再试；满足世界目标即成功，不要求抄参考解法。

章节层：同一词语工具进入新问题；先前的办法有时有效，有时要调整。结局保存孩子实际送回/摆放的东西，回访改变一个约束引发新的思考，不用货币或签到制造继续游戏的理由。

## 5. 语言工具的产品设计

WordSpell：围绕意义、有限造物和现有配额，字母可以点击/拖动/连线选择，但手势只是输入，不是学习效果。新物品具有真正用途，不作为完成题目的装饰奖品。

属性印块：small/big 等词能对多个允许的对象产生一致作用。视觉改变必须和通行、容量、可达性或支撑有关。它是词义应用工具，不要求初学者为了第一次缩小箱子先掌握复杂句型。

句子行动：Open the box.、Put…in/on… 等经内容规则接受的表达产生对应动作。语法正确但不可达，反馈操作阻挡；语言成立但不符合明确请求，反馈任务不匹配。

观察描述：The box is small. 或 The…is in/on… 读取当前状态，帮助朋友找物或回顾布置，不施法修改世界。多个同名物品时需要明确指代；不能把系统猜中的对象当孩子理解正确。

## 6. 学习、练习和探索如何共处

去冒险承担问题、选择与行动；魔法工坊承担可重复查看的词义和句型讲解、辅助练习、独立练习及自由试用；词语册承担已遇词句、实际使用记录和回访入口。三者使用相同语言内容和规则来源，但会话世界隔离。

同一个词可以经历“看见意义—辅助用过—独立条件下使用—换情境回访”。不要求每次工具使用都答拼写题；也不能让整个独立测查只靠卡片颜色和固定位置完成。游戏推理难度与语言难度独立控制，必要时通过提示继续游戏，同时诚实降低该次证据口径。

成人摘要不插入孩子每一步。内容应像“在文字提示下完成了放入指令；尚无独立回访”，而不是“语法掌握 100%”。记录是观察，不是正式测评认证。

## 7. 章节与回访

本工作包按 02 交付 R1 围栏取篮、R2 大小与装载、R3 指令交付与观察结局，以及一个条件改变的回访。各关展示同一小组机制的不同作用，不复制单独页面写四套判定。

R1 是先行判断点：两个不同策略由同一规则产生，不能把两段成功脚本称为多解。R2/R3 证明机制可迁移。回访使用手工验证变体；不引入不可控随机关卡，也不承诺无限重玩。

教学关可以只有一个清晰目标；不是每关都要多解。核心挑战必须留给孩子真实选择，教学和开放挑战的口径在界面与记录上能区分。

## 8. 视觉与角色

持续纸艺场景是主界面：暖纸、墨绿、赭黄、折页和墨迹形成辨识度。正式文字独立绘制，工具区不遮住操作对象。角色与道具独立资源，动作有起因、路径和终态。

狸花猫不是静态答题陪衬。它会观察目标、走向可达位置、尝试操作、遇阻并表现原因、发现新通路和庆祝。动作状态服务规则，不增加会自己改世界的“表演逻辑”。定位器画面右侧、项圈、围巾和背包遵循已确认形象，不镜像偷换姿态。

## 9. 取舍与禁止捷径

不以更换引擎保证游戏感；不以增加词数保证内容完整；不以求解器证明孩子感兴趣；不以长动画遮掩没有选择；不以音频播放证明听懂；不以一次通关证明掌握；不以新 Demo 截图证明正式入口已经切换。

当前不做经营/战斗/账号/社交/实时 AI。AI 的价值来自真实制作过程与产物，不来自虚构在线智能能力。缺乏教研或真机条件时分别报告，不能把它们隐藏在“工业级完成”中。

## 10. 何时可以说这版成立

工程结构成立：规则影响实际行为，两种核心解法可操作，因果可见，能撤销/恢复，完整章节与学习表面贯通。

内容成立：语言自然、意义明确、图音一致、帮助和接受表达经审核，没有误教描述/指令或指代混淆。

体验成立：适合的儿童在基本引导后能形成自己的办法、从后果调整，并有继续或尝试另一办法的行为证据。不能保证每个孩子喜欢，不能把一次小样本试用推成学习提升。

发布成立：当前版本必要检查、资源权利/录音/教研、真机与实际部署分别完成。详见 08。当前分支工程实现和本地证据见 STATUS；教研、真机、儿童与公开发布仍未完成，不由工程结果代替。
