# 03 · 交互、美术和音频规格

## 当前工程接入（2026-09-17）

WP-PLAYABLE-STORY-01 已用 `src/ui/tokens.css` 接入暖纸 #f5efdf、墨绿 #254b3d、赭黄 #c89845；标题用系统宋体/serif，字母用清晰的 Arial 小写。宽屏为场景与任务双栏，手机为紧凑场景＋任务＋字母盘，保留页面滚动；主操作至少 48px，字母至少 56px。`Letters`、`Scene`、`Art` 同时用于正式主线与 `/#design`。

`src/content/manifest.ts` 是资源替换入口，六个 SVG 均是本包原创临时矢量，非 GPT Image 成品。尺寸、字节数、Alpha、来源、版本、SHA-256 已登记，启动校验文件内容；失败有文字图示与重试。三幕背景为 CSS 纸页、小径、树和家门的临时布景，不冒充三张正式背景画。正式缺口：三幕背景、小猫一致性表情、物品精修、品牌授权与正式美术验收。

同一 manifest 登记六词及四句语音，路径均为 null、review=PENDING；AudioService 使用 en-US 浏览器完整词/句 TTS 开发替代，未生成音素。首次操作解锁、取消旧语音、重播、音量、静音、后台停止与失败辅助均已接入。实际发音、口音和教学质量仍需逐条审核。

截图及 Anti-AI-Generic 自检见 [工程验证](evidence/playable-story/README.md)，不等同正式美术或用户验收。

## 1. 页面与导航

首版页面：启动/资源检查 → 开场 → 故事场景 → 暂停设置 → 结局/绘本回顾 → 本地练习详情。工坊独立成人入口；隐藏按钮不是鉴权。初始化页面必须标“开发骨架”，未实现按钮不能假装已完成功能。

首页一项主操作“开始冒险”，有继续存档时增加“继续”和带确认的“重新开始”。不要求注册。暂停可调音量、重听当前任务、返回首页和清除记录；重新开始不能静默覆盖旧记录。

手机竖屏：顶部进度和暂停；中上部场景；中下部当前任务与重听/帮助；底部字母盘或选物操作。Pad 横屏增加场景空间，任务盘可在右侧，不简单拉伸手机截图。参考测试尺寸 360×640、390×844、768×1024、1024×768；这些是测试基准，不是对所有设备的保证。

## 2. 输入协议

字母点击→首个空槽；槽内点击→退回盘；拖到已有槽→交换。变形题固定未变化位，但不能在独立拼写题中偷偷锁定答案。施法按钮仅在输入结构完整时可用。用稳定字母 tokenId 区分相同字母，避免复制或丢字。

使用 Pointer Events，设置合理的 touch-action；在拖放元素上处理 pointercancel、指针捕获、手指离屏、屏幕旋转。不要给整个页面设 touch-action:none 而阻断必要滚动。不依赖原生桌面 HTML drag-and-drop，也不把 hover 当提示入口。[输入资料见来源文档]

点击物品后视觉选中；点击目标提交与拖放相同的领域命令。拖动容忍适度位移，落空复位；多指只接受当前 active pointer。动画与请求在处理中时阻止重复提交，但暂停/恢复不能永久锁死。

字母按钮建议最小约 56×56 CSS px，其他核心按钮至少约 48×48；在 360 宽度下采用受控列数/换行，不能为凑一排缩到无法触摸。无障碍目标需结合实际布局验证，不宣称仅凭尺寸符合全部标准。

## 3. 视觉语言与动效

纸张层次、温和背景、明显的字母对比；少量角色动作表现因果。场景从淡线稿逐步恢复颜色。字母使用清楚的小写形态，不旋转、不使用导致 a/g 难辨认的装饰字体。系统字体优先，不依赖第三方字体 CDN。

动作建议：选择反馈 100–180ms；施法/变形 450–800ms；错误反馈约 1 秒，重复时缩短。数值为设计预算，真机可调。prefers-reduced-motion 下直接淡入结果；不得靠 animationend 唯一推进业务。逻辑成功后刷新/跳过动画仍应保留结果。

错误投影是短期表现层对象，不写入正式 inventory。正式地图和垫子要有明显形态区别。主人公和 cat-card 的视觉尺寸/位置也必须不同，防止孩子以为同伴被变没。

## 4. 音频资源与播放服务

六个完整词音频；三个句子至少覆盖 Put the cap in the bag / Put the hat on the mat / Put the cat on the mat；Find the map；必要旁白与纠错。精确资产清单在内容包 manifest，资源全部是已审核草稿或正式产物，状态不可混用。

完整单词与音素素材分开。字母名称不是音素读音；不得将通用 TTS 对单字母的朗读用作拼读音。确定一种发音标准并让教研审核，不在一关中混用不同目标口音。

浏览器的首次点击应激活音频；Autoplay/AudioContext 失败要可观察。AudioService 统一控制：播放新任务取消旧任务语音；重听不会层层叠加；语音优先于环境音；离开页面或后台暂停，恢复时提供重听。绝不依赖背景音乐作为答题提示。

每页进入前预加载必需词音，其他按页懒加载；播放失败可重试。用户选择文字辅助后记录 inputMode=text-assisted；不能显示完整答案仍记纯听力完成。无需强制麦克风或 SpeechRecognition；浏览器语音合成仅可用作标注清楚的开发替代，不是正式教学语音。

## 5. 素材制作与权利记录

首版需要 3 张背景、1 个小猫角色及少量表情、6 类物品/纸偶、施法与修复状态、UI 控件。优先原创或公司授权素材。AI 图片需检查字母、手部、角色一致性，图片内不让模型生成需要准确识别的题目文字；字母由 DOM 渲染。

manifest 记录 assetId、路径、类型、word/scene 关联、审核状态、生成工具/作者、来源和授权备注；未确认许可的资源不进入公开构建。仅在确需时保存实际生成提示词，不能夹带公司内部资料或儿童照片。

## 6. 无障碍与故障交互

清晰焦点、语义按钮、键盘等价输入、不能只用颜色表示正确错误、尊重 reduced-motion。aria-live 播报简短结果，不在每次拖动时长篇打断。屏幕阅读辅助公开答案时如实标记辅助模式。

资源错误显示重试/返回；无存储权限仍可临时游玩，提示“本次进度可能不保留”；旧版本存档提供恢复或重开，不自动清空；旋转后重算布局并取消未完成拖动。页面最低可用性优先于装饰粒子和大幅动效。
