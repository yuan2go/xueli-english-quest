# 11 · 网页游戏产品架构与体验蓝图

版本：2026-09-20。本文补充 01/02 的产品合同，不建立第二套玩法规格。

## 产品方向
雪梨英语奇旅定位为“可操作世界中的儿童英语冒险”，不是把练习题套上插画。核心循环：**观察情境 → 理解语言 → 做出选择/操作 → 世界产生可见后果 → 获得反馈 → 继续探索或调整。**

语言任务必须尽量成为世界行为的原因：拼出 mat 得到可铺的垫子；组出 Put the cap in the bag. 真实收纳物品；描述句核对眼前布置。正确答案不是终点，世界状态改变才形成游戏反馈。

## 目标体验
儿童主体验：场景优先，练习工具按情境出现；每 30–90 秒出现一次有意义的行动、发现、变化或选择；允许合理顺序差异、试探、撤销和重玩；错误优先表现为世界没有按预期工作，而非红叉惩罚。学习内容嵌入任务，奖励优先采用世界反馈、角色反应、新路径、新组合与结局差异，不以金币/签到/抽卡替代玩法。

成人/教师体验不打断主流程。暂停或结局可查看本地学习摘要：独立、辅助、示范、回访、错误类型和实际完成行为；不得把一次成功推断为掌握。

## 页面与游戏空间
产品表面分为 Start、Adventure、Context Tool、Pause、Ending/Review。Adventure 不是传统页面列表；同一页面由 Scene + HUD + Context Tool 形成游戏空间。桌面/Pad 可场景与工具并排；手机保持场景可见，工具有界展开，不允许答题时完全失去世界上下文。

## 玩法层级
- Moment-to-moment：点击、拖放、开包、收纳、佩戴、变形、听音寻找、字母操作、词块组句。
- Encounter：一个情境问题，例如湿墨阻路：理解 map/mat → 改变纸张 → 铺路 → 角色通过 → 收回 → 恢复地图。
- Scene：若干 encounter 与自由互动组成一幕，允许条件驱动的局部非线性。
- Adventure：多个 Scene 构成故事弧；结局读取真实世界，而非固定完成页。
- Replay：活动变体、不同布置、帮助等级和回访提供重玩价值。

## 游戏感质量标准
页面游戏化必须同时满足 Agency、Causality、Continuity、Manipulation、Juice、Recovery、Pacing、Replayability：玩家选择真实改变状态；动作与结果因果明确；世界跨任务持续；核心对象直接操作；关键反馈及时克制；错误/取消/刷新可恢复；教学/操作/演出交替；存在有意义的顺序、布局或活动差异。不得以动画数量、组件数量或“使用游戏引擎”代替这些标准。

## 学习与游戏结合
学习对象分 Vocabulary、Spelling/Phonics、Grammar/Sentence、Listening、World Semantics。每个任务声明“语言目标 + 情境 + 世界效果/观察”，证据区分 teaching / assisted / independent / exploration / revisit。选词组句优先采用可执行指令和当前世界描述；逐步扩展语序和情境，不构建无限自然语言解析器。

## 产品边界
当前继续采用单机浏览器游戏：不需要账号、服务器权威状态、实时多人、聊天、支付或在线 AI。云存档/账号仅在明确出现跨设备需求后立项；实时多人只有玩法确实需要同步世界时才引入。

未来新增关卡应扩展内容和规则能力，而不是复制页面。若出现自由移动、连续碰撞、大量精灵/粒子、镜头系统等明确需求，再通过 ADR 评估 Phaser/Pixi/Cocos；不得为了“更像游戏”先换引擎。

## 成功口径
工程完成：正常入口可完成故事、刷新恢复、失败可退、目标设备布局可操作。体验完成：玩家能从场景理解目标，主要行动直接发生在世界中，连续练习感显著降低。教学完成需独立教研/儿童试玩证据。发布完成需资源权利、正式音频、真机和发布检查分别通过。

## 当前落地与下一验收
WP06 沿用确定性 world/adventure/save：无工具时是持续世界；对象行动、场景邀请和探索小路按需打开工具/活动。手机工具独立滚动，关闭即回世界；句尾落点与词块重排形成直接操作，普通成功不自动开始下一题。表现不阻塞操控或保存。

实际路径与工程自检见 STATUS；儿童趣味性、30–90 秒节奏目标、教学效果仍须真实观察，不能由自动化时长推定。下一阶段先以真实设备和目标儿童证据校准操控、语音和内容，不追加新引擎或平台。

六活动保留各自目标与可退出性：帽子搭配可比较阳光和风中的真实佩戴/掉落/入座后果；藏物活动利用遮挡、开包和位置描述；小帮手先安排座位或收好行李，再选择休息/启程。顺序与布置改变操作后果，主线世界保持隔离。没有额外刷题、计时惩罚或账号系统。
